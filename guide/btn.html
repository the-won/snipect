COMPONENT

Button

기본 클래스 .btn 에 변형(색상)·크기·너비 클래스를 조합해서 사용합니다.
<a>, <button> 모두 동일하게 적용됩니다.

1. 변형 (Variant)

용도에 따라 색상을 선택합니다. 화면당 주요 행동(Primary)은 1개를 권장합니다.

2. 크기 (Size)

기본(생략) / .btn-sm / .btn-lg

3. 상태 (State)

hover / focus 는 자동 적용됩니다. 비활성은 disabled 속성 또는 .disabled 클래스(링크용)를 사용합니다.

Link Disabled

4. 전체 너비 (Block)

.btn-block — 부모 너비를 100% 채웁니다. 모바일 하단 CTA 등에 사용합니다.

5. 아이콘 + 텍스트

.btn 은 inline-flex + gap 8px 이므로 아이콘과 텍스트를 나란히 두면 됩니다.

다음: 공지사항 →

6. 버튼 그룹

.btn-group — 모바일은 세로 쌓기, 576px 이상은 가로 중앙 정렬.

7. 입력 + 버튼 (Input Group)

.input-group — 입력창은 남는 너비를 채우고 버튼은 고정 폭입니다.

클래스 정리

클래스구분설명
.btn필수기본 버튼. padding 10×20, 14px, semibold, radius 8px
.btn-primary변형브랜드 컬러 배경(--accent), 흰 글자
.btn-outline변형흰 배경 + 테두리, hover 시 브랜드 컬러
.btn-danger변형삭제·취소 등 위험 동작(--danger)
.btn-sm / .btn-lg크기12px 작은 버튼 / 16px 큰 버튼
.btn-block너비width 100%
.btn-group레이아웃버튼 묶음. 모바일 세로 → 576px+ 가로 중앙
:disabled / .disabled상태opacity .5, 클릭 불가

※ 메인 히어로의 .btn-hero* 는 어두운 배경 전용 페이지 스타일이라 공통에서 제외했습니다. 필요하면 공통 변형(.btn-light 등)으로 승격하세요.
