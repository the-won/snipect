COMPONENT

Form Elements

라벨(.form-label) + 컨트롤 + 힌트(.form-hint)를 .form-group 으로 묶는 것이 기본 구조입니다.

1. 텍스트 입력

.form-input — input / select / textarea 공통 클래스. 필수 표시는 <span class="req">.

영문, 숫자, 특수문자 조합 8자 이상

2. 상태 (Error / Success / Disabled)

입력창에 .is-error / .is-success, 메시지에 .error / .success 를 함께 붙입니다.

✕ 비밀번호가 일치하지 않습니다.

✓ 사용 가능한 아이디입니다.

3. Select / Textarea

select 는 기본 화살표를 제거하고 커스텀 화살표를 사용합니다. 작은 select 는 .form-input-sm.

0 / 200자

4. 체크박스 / 라디오

label.form-check 로 감싸면 라벨 클릭 영역과 정렬이 자동 처리됩니다. 가로 나열은 .form-check-group.

5. 토글 스위치

.toggle 에 .on 클래스를 토글합니다. (접근성 필요 시 role="switch" + aria-checked 추가)

이메일 알림 서비스 업데이트, 혜택 정보를 이메일로 받습니다
마케팅 수신 동의 프로모션, 이벤트 안내 (선택)

6. 파일 업로드

.file-upload — 점선 영역. 실제 input[type=file] 과 연결해서 사용합니다.

📁
파일을 드래그하거나 클릭하세요
JPG, PNG / 최대 5MB

7. 그리드 레이아웃

.form-row 모바일 1열 → 768px+ 2열 / .form-row-3 모바일 1열 → 576px+ 3열
