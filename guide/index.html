UI GUIDE

컴포넌트 가이드

현재 5개 페이지(html/)에서 반복되는 UI를 분석해 공통화한 컴포넌트 문서입니다.

디자인 토큰

색상·타이포·간격·라운드 변수 (token.css)

버튼

primary / outline / danger, 크기, 상태, 그룹

폼 요소

input, select, textarea, 체크/라디오, 토글, 파일, 그리드

기타 컴포넌트

배지, 탭필터, 페이지네이션, 카드, 테이블, 타이포

폴더 구조

/
├─ html/                서비스 페이지 (01-main ~ 05-products)
├─ guide/               컴포넌트 가이드 (이 문서)
└─ resources/
   ├─ css/
   │  ├─ token.css      디자인 토큰 (먼저 로드)
   │  ├─ common.css     공통 컴포넌트
   │  └─ guide.css      가이드 문서 전용
   └─ js/guide.js       가이드 코드 블록 자동 생성

로드 순서: token.css → common.css → (페이지 전용 <style>)
