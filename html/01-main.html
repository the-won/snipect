모바일 퍼스트

기본 스타일이 모바일. min-width 미디어 쿼리로 태블릿 → 데스크톱 확장.

🔤

rem 기반 타이포

html font-size: 16px 고정. rem값 × 16 = px값. 소수점 없이 깔끔하게.

📏

직접 값 표기

var() 대신 0.875rem(14px), 1.5rem(24px) 직접 표기로 학습 편의성 향상.

📊

반응형 그리드

CSS Grid의 repeat()와 minmax()로 컬럼 수 자동 조절.

🧩

컴포넌트 패턴
